# MOUSE DROID

This is a repo for my project of building my first RC Vehicle: a Mouse Droid from Star Wars!

For now, we have in this repo:
* controls/controls.ino: Arduino sketch for issuing commands to motors. 
* ir_test/ir_test.ino:   Checks for incoming signal read by KY-022 and writes to serial port 9600 baud

Components used (so far):
* L298N x 2 
* Standard DC motors x 4
* Arduino Hero (Uno) Board x 1
* KY-022 IR Reciever
* Generic IR remote (w/ CR2025 battery)
* Zeee 2200 mAh (50C 7.4V 16.28Wh) Polymer Battery
